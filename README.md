An elegant Lovelace card for Home Assistant that displays a person's profile picture, status, battery and Wi-Fi status, and proximity. Includes a smart editor with automatic device and sensor detection.

## Installation via HACS (Custom Repository)
1. Open HACS in Home Assistant.
2. Go to **Frontend**.
3. Click the three dots in the upper right corner and select **Custom Repositories**.
4. Paste the URL of your GitHub repository and select **Lovelace** as the category.
5. Click **Add** and install the card.



# Person Details Card für Home Assistant

Eine elegante Lovelace-Karte für Home Assistant, die das Profilbild, den Status, den Batterie- und WLAN-Status sowie die Entfernung (Proximity) einer Person anzeigt. Inklusive intelligentem Editor mit automatischer Geräte- und Sensoren-Erkennung.

## Installation über HACS (Custom Repository)
1. Öffne HACS in Home Assistant.
2. Gehe auf **Frontend**.
3. Klicke auf die drei Punkte oben rechts und wähle **Benutzerdefinierte Repositories** (Custom repositories).
4. Füge die URL deines GitHub-Repositories ein und wähle als Kategorie **Lovelace**.
5. Klicke auf **Hinzufügen** und installiere die Karte.
